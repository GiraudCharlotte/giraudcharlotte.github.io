# Charlotte Giraud

Site académique bilingue de Charlotte Giraud, enseignante certifiée et chercheuse en histoire contemporaine.

- Français : https://giraudcharlotte.github.io/
- English : https://giraudcharlotte.github.io/en/
- CV en français : https://giraudcharlotte.github.io/assets/pdf/CV_Charlotte_Giraud.pdf

Les textes français et anglais sont dans `_pages/fr/` et `_pages/en/`. Les programmes des conférences et le CV sont partagés dans `assets/pdf/`.

Voir [le guide de maintenance](MAINTENANCE.md) pour modifier le contenu, compiler le CV et publier. Les sources originales fournies pour la création du site sont conservées séparément et ne sont pas incluses dans le dépôt.

Créé à partir du starter [al-folio](https://github.com/alshedivat/al-folio), avec les conventions multilingues de [multi-language-al-folio](https://github.com/george-gca/multi-language-al-folio) et [Jekyll Polyglot](https://github.com/untra/polyglot). Les licences et guides upstream sont conservés.
